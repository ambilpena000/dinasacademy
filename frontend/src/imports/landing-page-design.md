(Landing Page Modern)

Prompt:

Design a modern, clean, and visually appealing landing page for an online learning platform that helps students prepare for university entrance exams (PTN) and Indonesian government college exams (Sekdin).

The design should feel modern, elegant, and friendly, with a soft gradient color palette dominated by purple, blue, and subtle pink tones, creating a sense of motivation, trust, and professionalism.

Avoid a rigid or corporate look. Instead, aim for a smooth, slightly playful but still premium educational platform aesthetic, similar to modern startup landing pages.

Use large spacing, rounded corners, soft shadows, and glassmorphism elements to make the UI feel light and modern.

The layout should be minimal, not crowded, with clear visual hierarchy and smooth section transitions.

Hero Section

Create a strong hero section with a large bold headline, highlighting the message:
“Lolos ke Perguruan Tinggi Impianmu”.

Use gradient text or gradient underline accent to emphasize the key phrase.

Add a short supporting paragraph explaining the platform benefits: video lessons, CAT tryouts, analytics, and mentorship.

Include two buttons:

Primary: “Mulai Belajar Gratis”

Secondary: “Lihat Review”

The primary button should use a vibrant gradient (blue → purple) with soft glow hover effects.

On the right side, place a modern illustration or photo of students studying together, with floating UI cards showing:

tryout score

ranking badge

acceptance notification

Features Section

Create a “Fitur Unggulan” section with 6 feature cards arranged in a clean grid.

Each card should contain:

colorful gradient icon

bold feature title

short description

Use soft neumorphic cards or floating cards with subtle shadows.

Features include:

Video Materi HD

Try Out CAT Real

Rekomendasi PTN

Analisis Performa

Mentor Berpengalaman

Gamifikasi Belajar

Testimonials Section

Design a visually engaging testimonial section that feels trustworthy and dynamic.

Use a large gradient background card highlighting one main success story from a student who passed a top university.

Display:

profile photo

quote

star rating

final tryout score

accepted university

Below the main testimonial, add smaller testimonial cards in a grid layout, each containing:

avatar illustration

name

university

short quote

improvement score badge

Use subtle gradients and soft shadows to keep the design modern but not too busy.

Call To Action Section

Create a strong final call-to-action section with a large centered headline:
“Siap Raih Impianmu?”

Add a big gradient button:
“Daftar Sekarang – GRATIS!”

Include small trust indicators below the button:

Tanpa kartu kredit

Akses instan

Garansi 7 hari

Use a soft gradient background with subtle glowing shapes or abstract gradient blobs to make the section visually attractive.

Design Style Guide

The overall design should follow these style guidelines:

Modern startup landing page aesthetic

Smooth purple–blue gradients

Large whitespace for readability

Rounded corners (16–24px radius)

Soft shadows and glassmorphism effects

Clean typography similar to modern SaaS products

Friendly but professional educational branding

Avoid overly crowded layouts and keep the interface simple, clean, and engaging.
